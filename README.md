# SPL Pocket

Privacy policy and support pages for SPL Pocket, an iOS app for Splunk Enterprise administrators.

- Privacy Policy: https://thsngnr.github.io/spl-pocket/privacy.html
- Support: https://thsngnr.github.io/spl-pocket/support.html
- Release list read by the app: https://thsngnr.github.io/spl-pocket/versions.json (rebuilt every 6 hours by `.github/workflows/versions.yml` from Splunk's public sites, Splunkbase and GitHub; `python3 scripts/build_versions.py` runs it locally)

Questions and bug reports: open an issue in this repository.
